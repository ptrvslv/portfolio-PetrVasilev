# portfolio-PetrVasilev
# Portfolio: Junior Data Analyst | Product Analyst | BI Analyst

Привет! Меня зовут Петр, я начинающий Data Analyst. За плечами у меня сильная база в коммерческой и корпоративной юриспруденции, а также практический опыт в решении аналитических задач, построении дашбордов и продуктовых метрик.

Этот репозиторий содержит мои учебные и пет-проекты, демонстрирующие владение современным стеком для работы с данными.

---

## 🛠 Стек технологий

* **Языки программирования:** Python (Pandas, NumPy, SciPy, Matplotlib, Seaborn)
* **Базы данных и SQL:** PostgreSQL, сложные запросы, агрегации, оконные функции
* **Инструменты BI и визуализации:** Yandex DataLens
* **Аналитика:** продуктовые метрики, когортный анализ, юнит-экономика, A/B тестирование
* **Инструменты разработки:** Git, GitHub, Jupyter Notebook

---

## 📂 Структура репозитория

В репозитории собраны проекты, охватывающие полный цикл аналитической задачи: от выгрузки и очистки сырых данных до построения графиков и формирования выводов для бизнеса.

* **`cb_investments.ipynb`** — комплексный исследовательский проект по анализу венчурных инвестиций и стартапов (очистка данных, работа с выбросами, анализ раундов финансирования).
* *Другие проекты и скрипты будут добавляться по мере развития портфолио.*
